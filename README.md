Easy Shopping Via Mobile
Responsive landing page developed as the first practical challenge of the DevClub course.
Landing page responsiva desenvolvida como o primeiro desafio prático do curso DevClub.

🛠️ Technologies Used / Tecnologias utilizadas

HTML5

CSS3

Google Fonts (Oswald)

Responsive Design (Media Queries) 

📱 About the Project / Sobre o projeto

A landing page for a mobile store featuring a two-column layout on desktop that adapts to a single column on mobile devices (breakpoint: 600px).
Página de apresentação de uma loja mobile com layout de duas colunas no desktop que se adapta para uma única coluna em dispositivos móveis (breakpoint: 600px).

✨ Features / Funcionalidades

Flexible layout using Flexbox / Layout flexível com Flexbox
Responsive typography using the clamp() function / Tipografia responsiva com clamp()
Full responsiveness for screens smaller than 600px / Adaptação completa para telas menores que 600px
Hover and active states for buttons and navigation links / Efeitos de hover e active em botões e links de navegação
